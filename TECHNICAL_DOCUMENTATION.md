# Техническая документация `country-phone-mask`

Версия пакета: `1.9.2`. Это браузерный JavaScript/TypeScript-компонент, который создаёт поле `input[type="tel"]` внутри переданного контейнера, показывает список стран с флагами из SVG-спрайта и форматирует номер по маске.

## Назначение и границы

Плагин отвечает за отображение и редактирование номера. Он **не** валидирует номер, не сообщает о его готовности, не отправляет форму сам и не предоставляет методов чтения/установки значения после инициализации. В форму уходит обычное текущее значение созданного `input`; незаполненные позиции маски остаются символами `_`.

Поддерживаются ESM, CommonJS и типы TypeScript. Пакет не имеет runtime-зависимостей.

## Подключение

```ts
import createPhoneInput, { countries } from 'country-phone-mask';
import 'country-phone-mask/dist/index.css';

const phone = createPhoneInput({
    container: document.querySelector<HTMLElement>('.phone-input')!,
    countries,
    spritePath: '/icons/sprite.svg',
    defaultCountry: 'RU',
});
```

Контейнер должен существовать до вызова. Каждый вызов добавляет в него новый `.phone-input-wrapper`; перед повторной инициализацией прежний экземпляр нужно уничтожить через `destroy()`.

Для CommonJS:

```js
const phoneMask = require('country-phone-mask');

const phone = phoneMask.default({
    container: document.querySelector('.phone-input'),
    countries: phoneMask.countries,
});
```

## Публичный API

```ts
interface Country {
    name: string;
    code: string;
    dialCode: string;
    mask: string;
}

interface PhoneInputOptions {
    container: HTMLElement;
    countries: Country[];
    spritePath?: string;
    apiKey?: string;
    defaultCountry?: string;
}

interface PhoneInputInstance {
    addCountries(newCountries: Country[]): void;
    destroy(): void;
}
```

`createPhoneInput(options)` возвращает `PhoneInputInstance`.

| Параметр | Обязателен | Поведение |
| --- | --- | --- |
| `container` | Да | Узел, куда добавляется интерфейс поля. Настройки из `data-*` считываются именно с него. |
| `countries` | Да | Изменяемый массив стран. Можно импортировать готовый `countries`. |
| `spritePath` | Нет | Путь к SVG-спрайту; по умолчанию `./icons/sprite.svg`. |
| `apiKey` | Нет | Токен для запроса к `ipinfo.io`. Без токена запрос всё равно будет выполнен, если потребуется геоопределение. |
| `defaultCountry` | Нет | ISO-подобный код страны. Сравнение без учёта регистра; имеет наивысший приоритет. |

### Методы экземпляра

`addCountries(newCountries)` добавляет страны, чьих `code` ещё нет, и заново рисует список. Сравнение кодов чувствительно к регистру. Метод изменяет исходный массив, переданный в `options.countries`. Текущая страна не меняется.

`destroy()` удаляет созданную обёртку и снимает зарегистрированные слушатели. Асинхронный запрос геоопределения не отменяется: если он завершится после `destroy()`, обработчик всё ещё может попытаться изменить уже удалённые DOM-узлы.

### Экспортируемые функции

```ts
digitsOnly(value: string): string
findCountryByDial(digits: string, countries: Country[]): Country | undefined
formatDigitsToMask(digits: string, mask: string): string
```

- `digitsOnly` удаляет все нецифровые символы.
- `findCountryByDial` выбирает страну с самым длинным кодом, который совпадает с началом строки цифр. Дефисы в `dialCode` игнорируются.
- `formatDigitsToMask` последовательно заменяет `_` цифрами, оставляет незаполненные `_`, а цифры сверх длины маски добавляет в конец результата.

## Данные и маски

Встроенный экспорт `countries` содержит список стран и специальную запись:

```ts
{ name: 'None Country', code: 'NONE', dialCode: '', mask: '' }
```

`NONE` показывает поле без флага, кода и маски. В маске `_` означает позицию для одной цифры; все прочие символы являются неизменяемым форматированием. Коды страны должны быть уникальными. У России и Казахстана общий `+7`: по одному лишь номеру будет выбран первый подходящий код из списка (сейчас `RU`), поэтому для Казахстана нужно явно задавать `defaultCountry: 'KZ'` или выбирать страну пользователем.

## Атрибуты контейнера

```html
<div
  class="phone-input"
  data-name="phone"
  data-id="phone-field"
  data-value="+79612035444"
  data-clue="Введите номер телефона"
></div>
```

| Атрибут | Результат |
| --- | --- |
| `data-name` | Значение `name` созданного `input`. |
| `data-id` | Значение `id` созданного `input`. |
| `data-value` | Начальный номер. Все нецифровые символы удаляются перед форматированием. |
| `data-clue` | Текст подсказки над полем, видимый только при фокусе. Вставляется через `textContent`, HTML не исполняется. |

Опции JavaScript не заменяют эти атрибуты: для `name`, `id`, начального значения и подсказки других публичных параметров нет.

## Выбор начальной страны и геолокация

Приоритет следующий:

1. `defaultCountry`, если соответствующий код есть в массиве;
2. страна, определённая по префиксу `data-value`;
3. `NONE`, затем `NA`, затем первый элемент массива.

Только в третьем случае запускается `fetch('https://ipinfo.io/country')`; при наличии `apiKey` URL становится `https://ipinfo.io/country?token=...`. В ответ ожидается двухбуквенный код страны в тексте. При успехе выбранная страна заменяет fallback, но введённое `data-value` не перезаписывается. При ошибке в консоль выводится `Geo detection failed:` и остаётся fallback.

Это сетевой запрос на сторонний сервис. Для предсказуемого интерфейса и отсутствия запроса следует всегда передавать существующий `defaultCountry` либо `data-value` с распознаваемым кодом.

## Ввод и DOM-поведение

Создаётся следующая структура:

```html
<div class="phone-input-wrapper">
  <div class="country-dropdown">
    <button class="current-country" type="button">…</button>
    <div class="country-options">
      <button class="country-option selected" type="button">…</button>
    </div>
  </div>
  <input type="tel">
</div>
```

Для любой страны с маской начальное поле содержит полную маску, например `+7 (___) ___-__-__`. Код страны защищён: `Home`, движение влево, Backspace/Delete и печатные символы не дают курсору или редактированию выйти в область до первой позиции `_`. При вставке и обычном вводе значение очищается до цифр и форматируется заново.

Вставка через Ctrl+V заменяет весь номер. Для выбранной России или Казахстана полные номера `+79612035444` и `89612035444` приводятся к `+7 (961) 203-54-44`: международный `+7` либо национальная начальная `8` удаляются до применения маски. Номер без кода, например `9612035444`, вставляется без удаления цифр. Для других стран международный код удаляется, когда исходный текст начинается с `+` и совпадает с кодом выбранной страны.

Выбор другой страны очищает номер полностью и заменяет его новой маской. Список открывается только по кнопке текущей страны; закрытия по Esc, клику вне списка или смене фокуса нет.

## Флаги и стили

Флаг вставляется как `<use href="${spritePath}#${code}">`; в спрайте должны быть символы с id кодов, например `#RU`. Пакет публикует спрайт как `dist/icons/sprite.svg` и CSS как `dist/index.css`.

Стили используют фиксированные классы без CSS-переменных: ширина обёртки до `320px`, выпадающий список `220px` и высотой до `200px`, его `z-index` равен `10`. Для интеграции дизайн обычно переопределяют селекторами `.phone-input-wrapper`, `.country-options`, `.country-option` и `.phone-input-wrapper input[type="tel"]` после импорта CSS.

## Сборка и состав публикации

```bash
npm install
npm run build
```

Скрипт Rollup собирает `src/index.ts` в `dist/index.esm.js` и `dist/index.cjs`, генерирует декларации `dist/index.d.ts`, минифицирует CSS и копирует спрайт в `dist/icons/sprite.svg`. В `package.json` объявлены точки входа ESM, CommonJS, типы и CSS. `prepublishOnly` автоматически запускает сборку перед публикацией.

## Ограничения, значимые для доработок

- Нет событий (`change`, `countrychange`), геттеров, сеттеров и публичного доступа к созданному `input`.
- Валидации полноты/корректности номера нет; `_` и лишние цифры могут попасть в отправляемое значение.
- Страны добавляются только в конец и только без дубликата `code`; удалить или заменить страну API не позволяет.
- Смена страны безусловно стирает введённый номер.
- Нет проверок аргументов: пустой `countries` приведёт к ошибке при обращении к маске fallback-страны.
- Геоопределение запускается безусловно для fallback и может быть нежелательно для приватности, CSP или офлайн-сценариев.
- В пакете отсутствуют тестовые скрипты и автоматические тесты; перед изменениями стоит добавить покрытие для масок, каретки, вставки, выбора страны и геоопределения.
